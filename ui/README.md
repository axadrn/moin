# moin UI

The UI moin runs on: native HTML, CSS and JS for any stack. No build step, no Tailwind. Copy the folder into your repo and it is your code.

Experimental. It can change or disappear at any time.

```html
<link rel="stylesheet" href="ui/moin.css">
<script src="ui/moin.js"></script>
```

Docs, components, blocks and the theme editor: [moin.run/ui](https://moin.run/ui).

See `LICENSE`.
