A logo on a white tile, or a first letter on an ink tile. The white tile stays white in both themes, so any logo reads on it.

Styles: `components/avatar.css`.

```example
app-icon
```

`data-letter` is the tile for a first letter. `data-large` is as high as a title. `data-lead` puts it in front of an item.
