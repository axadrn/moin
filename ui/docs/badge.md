A word that labels something.

Styles: `components/badge.css`.

```example
badge
```

## Mark

A round answer as high as a line. `data-kind` is `yes`, `part` or `no`. With no kind it is a blank that keeps the words next to it in line. Give it `role="img"` and an `aria-label`, because it only shows a sign.

```example
badge-mark
```
