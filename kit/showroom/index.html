The experimental UI kit moin runs on.

Native HTML, CSS and JS for any stack. 33 KB gzipped. Your code, not a library.

Start Rooms Parts Layout Foundation

Get started

1. Get the folder

curl -L https://github.com/axadrn/moin/archive/main.tar.gz | tar xz --strip-components=1 moin-main/kit

2. Link it

<link rel="stylesheet" href="kit/kit.css">
<script src="kit/kit.js"></script>

3. Copy a room

Open the rooms

Use it as plain HTML, or turn parts into components in your stack.

Where everything lives

kit/

├── foundation.css     floor 1
├── layout.css         floor 2

├── icons/             the drawings
├── kit.js             the power
├── docs/              one page per part
├── examples/          one file per example
├── rooms/             whole pages to copy
├── showroom/          this page
├── CHANGELOG.md       what changed
├── LICENSE            MIT
└── README.md

How it is built

Like a house: each floor stands on the one below.

Rooms
Whole pages to start from.
Parts
Buttons, lists, cards.
Layout
Where things stand.
Foundation
Colors, spacing, corners.

The rules

A value exists once

On the ground floor, in foundation.css.

A higher floor wins

CSS does that by itself, with layers.

A page is only HTML

Kit classes, and no CSS of its own.

One dial, everything follows

Turn the radius and every corner moves.

It is your code

Copy the folder into your repo and change what you want.

Your font

        
The kit uses the system's fonts, so there is nothing to load. Pick another one above and Copy theme gives you these lines for it.

        
<link rel="preload" href="/fonts/inter.woff2" as="font" crossorigin>

@font-face {
  font-family: "Inter";
  src: url("/fonts/inter.woff2") format("woff2");
  font-weight: 100 900;
  font-display: optional;
}
:root {
  --font-sans: "Inter", system-ui, sans-serif;
}
